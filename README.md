# Sleeper NBA dashboard

Published copy of a personal Lock-In dashboard: https://abszd.github.io/sleeper_prediction_dashboard/

Generated on the owner's PC and pushed here automatically after each rebuild. This repo only holds the built page
(`index.html`) and its version stamp; the code, model and data are not here. Live scores on the page are fetched by
your browser from Sleeper's and ESPN's public APIs.
